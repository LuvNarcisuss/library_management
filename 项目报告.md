# 图书管理系统项目报告

## 1. 项目概述

### 1.1 项目背景
随着信息技术的发展，传统的手工图书管理方式已经无法满足现代图书馆的管理需求。为了提高图书管理的效率和准确性，开发一套基于Web的图书管理系统显得尤为必要。

### 1.2 项目目标
本项目旨在开发一套功能完善、操作便捷的图书管理系统，实现图书、读者、借阅等信息的数字化管理，提高图书馆的管理效率和服务质量。

### 1.3 项目范围
- 图书信息管理
- 读者信息管理
- 借阅记录管理
- 数据统计与查询

### 1.4 技术栈

| 分类 | 技术 | 版本 |
|------|------|------|
| 后端框架 | Spring Boot | 2.7.14 |
| 数据访问 | Spring Data JPA | 2.7.14 |
| 数据库 | MySQL | 8.0.33 |
| 前端框架 | Vue.js | 2.6.14 |
| UI组件库 | Element UI | 2.15.12 |
| 构建工具 | Maven | 3.8.1 |
| 前端构建 | Vite | 4.4.5 |
| HTTP客户端 | Axios | 0.27.2 |

```vue
<template>
```

```vue
      <div slot="header" class="login-header">

      <el-form :model="loginForm" :rules="loginRules" ref="loginForm" class="login-form">
        <el-form-item prop="username">
          <el-input

            prefix-icon="el-icon-user"

        </el-form-item>
        
        <el-form-item prop="password">
          <el-input

            clearable
          ></el-input>
        </el-form-item>
        
        <el-form-item>
          <el-button type="primary" @click="handleLogin" class="login-button" :loading="loginLoading">

<script>
import axios from 'axios'

export default {
  data() {
    return {
      loginForm: {
        username: '',
        password: ''
      },
      loginRules: {
        username: [
          { required: true, message: '请输入用户名', trigger: 'blur' },
          { min: 3, max: 20, message: '用户名长度在 3 到 20 个字符', trigger: 'blur' }
        ],
        password: [
          { required: true, message: '请输入密码', trigger: 'blur' },
          { min: 6, max: 20, message: '密码长度在 6 到 20 个字符', trigger: 'blur' }
        ]
      },
      loginLoading: false
    }
  },
  methods: {
    handleLogin() {
      this.$refs.loginForm.validate((valid) => {
        if (valid) {
          this.loginLoading = true
          axios.post('/login', this.loginForm)
            .then(response => {
              const { user } = response.data
              // 保存用户信息到localStorage
              localStorage.setItem('user', JSON.stringify(user))
              this.$message.success('登录成功')
              // 跳转到主页面
              this.$router.push('/')
            })
            .catch(error => {
              const message = error.response?.data?.message || '登录失败'
              this.$message.error(message)
            })
            .finally(() => {
              this.loginLoading = false
            })
        }
      })
    }
  }
}
</script>
```

### 7.1 问题修复情况

#### 7.1.1 登录失败问题（已解决）
**问题描述**：用户输入正确的用户名和密码后，系统提示"登录失败"。

**原因分析**：前端Login.vue组件中API请求路径存在冗余的`/api`前缀。由于在main.js中已经配置了Axios的baseURL为`/api`，而Vite代理配置会将`/api`前缀转发到后端，导致实际请求路径变为`/api/api/users/login`，造成404错误。

**修复方案**：
- 修改`frontend/src/components/Login.vue`中的登录请求路径，将`/api/users/login`改为`/users/login`

#### 7.1.2 登录后404错误（已解决）
**问题描述**：用户成功登录后，访问图书管理、读者管理等页面时出现404错误。

**原因分析**：与登录失败问题类似，BookManager.vue、ReaderManager.vue和BorrowManager.vue组件中的API请求路径都包含了冗余的`/api`前缀。

**修复方案**：
- 修改`frontend/src/components/BookManager.vue`中的6个API请求，移除`/api`前缀
- 修改`frontend/src/components/ReaderManager.vue`中的6个API请求，移除`/api`前缀
- 修改`frontend/src/components/BorrowManager.vue`中的3个API请求，移除`/api`前缀
